# Automation Rules Engine

Visual rule builder for creating "if this, then that" automations. Supports time-based triggers, device state conditions, and multi-action sequences.

## Acceptance Criteria

- Drag-and-drop rule builder
- Trigger types: time, device state, location, weather
- Action types: device control, notifications, scenes
- Rule testing and simulation mode
