# Dashboard & Widgets

Customizable home dashboard with drag-and-drop widgets for device control, status monitoring, and quick actions.

## Acceptance Criteria

- Widget library (thermostat, lights, cameras, etc.)
- Drag-and-drop layout editor
- Multiple dashboard pages
- Responsive grid system
