# Voice Command Parser

Natural language processing pipeline that converts spoken commands into structured device actions. Handles ambiguity, context, and multi-step requests.

## Acceptance Criteria

- Intent classification for 50+ command types
- Entity extraction (device names, rooms, values)
- Context-aware disambiguation
- Fallback to clarification questions
