# Storage format — organization in roadmap.json

Move card **organization** out of per-card frontmatter and `roadmap-index.md`
into a single per-vault `roadmap.json` that is sectioned by view and versioned.
Card Markdown stays the source of truth for content; parent links stay in
frontmatter.

Design: [`kando/docs/roadmap-json.md`](https://github.com/mattcrest/kando/blob/main/docs/roadmap-json.md).
