# kando-roadmap

Roadmap vault for **Kando itself** — the planning board for Kando's own work,
and the first real dogfood of Kando's `roadmap.json` storage format.

- Cards: `initiative-*.md`, `release-epic-*.md`, `release-*.md` (Markdown).
- Organization: [`roadmap.json`](roadmap.json) (columns, order, strategy lanes).
- Conventions: [`roadmap-conventions.md`](roadmap-conventions.md).
- Format design: [`kando/docs/roadmap-json.md`](https://github.com/mattcrest/kando/blob/main/docs/roadmap-json.md).

Point Kando at this directory as a vault in `vaults.json`.
